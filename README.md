Storage Estimator

Purpose

This program converts a storage size from gigabytes (GB) to megabytes (MB). It was written for CS-117 Introduction to ICT (Lab 10) and is now tracked with Git and GitHub as part of Lab 11.

How to Run
Install Python on your computer.
Open a terminal in this folder.
Run the program with: python storage_estimator.py (On some Macs, use python3 storage_estimator.py.)
When asked, type a storage size in GB and press Enter.
Example Input/Output
Enter storage in GB :2
Storage in MB:  2048.0

The program multiplies the GB value by 1024 to get the size in MB.
